# Salúva POS & Cafe Manager

Crea una aplicación web para una cafetería local llamada “Salúva”.

La app debe funcionar como un punto de venta inteligente para una cafetería. Debe tener una estética cálida, moderna, minimalista y premium, con colores inspirados en café, crema, verde suave y tonos naturales.

La aplicación debe estar en español y debe incluir estos módulos principales:

Dashboard general

Punto de venta / caja

Pedidos activos

Menú y productos

Inventario

Reportes de ventas

Configuración del negocio

Debe haber una barra lateral de navegación y una interfaz pensada para usarse en tablet, laptop o computadora de mostrador.

Usa datos de ejemplo realistas para una cafetería: café americano, latte, cappuccino, matcha, chai, panqué, croissant, galletas, desayunos ligeros, etc.

El objetivo es que Salúva pueda vender desde el mostrador, controlar pedidos, revisar ventas del día y llevar inventario de ingredientes.
